# VANGUARD // Men's Atelier

> **Avant-Garde Menswear, Technical Outerwear & Avant-Garde Accessories**  
> An animation-rich, high-fashion e-commerce experience designed with brutalist editorial aesthetics, interactive 3D physics, a real-time Style Lab outfit studio, and a complete shopping & checkout flow.

---

## ✨ Features

- **Editorial 3D Hero Experience**:
  - Interactive 3D mouse parallax tilt on the featured outerwear card with dynamic perspective lighting.
  - Live capsule countdown clock for upcoming drops.
  - Web Audio API haptic feedback engine (subtle clicks, wishlist pops, and checkout chimes) with master mute toggle.
- **Interactive "Style Lab" Outfit Studio**:
  - Mix and match 5 layers in real-time (Outerwear + Top + Bottoms + Footwear + Accessories).
  - Dynamic combined retail price calculation with an automatic **15% Bundle Discount**.
  - One-click "Add Complete Look to Cart" and a "Shuffle Look" randomizer.
- **Shoppable Editorial Lookbook**:
  - Shibuya night photography with pulsing radar hotspot pins.
  - Tap any pin to reveal garment specs and add pieces directly to the bag.
- **Dynamic Catalog & Filtering**:
  - Category filters (*Outerwear*, *Hoodies & Tops*, *Cargos & Bottoms*, *Footwear*, *Accessories*).
  - Price range slider, edition badges filter (*Limited Drop*, *Bestseller*, *Exclusive*), and live search.
- **Product Card Experience**:
  - Smooth dual-photo hover crossfade.
  - Slide-up quick size selector tray.
  - Animated wishlist heart with haptic chime.
  - Colorway swatches with real-time state.
- **Quick View Modal**:
  - Multi-angle image gallery with thumbnail navigation.
  - Accordion tabs for Fabric Specifications, Fit & Model dimensions, and Care guidelines.
- **Slide-Out Cart & Free Shipping Meter**:
  - Animated progress bar toward the $250 free worldwide shipping threshold.
  - Working discount code engine (e.g. `TRENDY20` for 20% off, `VANGUARD10` for $10 off, `STYLELAB15` for 15% off).
  - Item quantity steppers and subtotal calculations.
- **Interactive Multi-Step Checkout**:
  - 3-step wizard: Shipping Address &rarr; Simulated Card / Apple Pay Payment &rarr; Confetti fireworks order confirmation with printable receipt.
- **Multi-Currency Switcher**:
  - Real-time conversion across USD ($), EUR (€), GBP (£), and JPY (¥).

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom cyber-streetwear design tokens
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio Synthesis**: Native Web Audio API

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Jeswin1127/trendy-mens-fashion.git
cd trendy-mens-fashion
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### 4. Build for production
```bash
npm run build
```
